The family's day, at a glance by the front door.

Turn an old iPad into a wall dashboard: one agenda for the whole family, the kids' activities and what goes in each backpack, weather, live traffic and family photos. It runs on a PC at home — even on an iPad 2.

That iPad 2 that has spent the last three years as a very expensive paperweight in the kitchen drawer? It has a job again.

Everything the family needs before leaving home

Designed to be read from across the hallway in two seconds, and managed from your phone.

One agenda

iCloud and Outlook calendars, the kids' appointments, birthdays and household deadlines (car inspection, insurance, ID cards) in a single list for the next 30 days.

The kids' week

School hours and weekly activities, one line each, with the days and what to bring. Activities pause on their own during holidays.

“Don't forget”

Everything that goes in each child's backpack, gathered from the timetable and activities. From 6 pm it shows tomorrow's list.

Weather that matters

Now, the next hours and the week, with UV, wind, air quality, pollen, sunrise and sunset. Official weather warnings appear only when there are any.

Live traffic optional

Minutes from home to work and school, coloured green, orange or red, with the destinations of the day: workplaces on weekdays, family at the weekend.

Family photos

Photos from a folder fill the free space during the day and the whole screen at night. iPhone HEIC photos are converted automatically.

Managed from your phone

A web page to add activities, birthdays, deadlines and destinations, protected by a PIN. No app to install.

A calendar for every iPhone

Activities, school days, birthdays and deadlines are published as a calendar each family member can subscribe to.

School calendar built in

Portuguese public holidays (including Easter) and the national school calendar, with countdowns to the next breaks. A municipal holiday is one line of configuration.

How it works

A small Node.js server on a PC at home does all the work. The iPad only has to show one page.

Sources

  • Calendars (ICS links)
  • Open-Meteo and IPMA
  • TomTom or OSRM
  • A photo folder
→

Server at home

server.js fetches everything, keeps the family data in a local JSON file and serves a single request to the iPad.

→

Screens

  • iPad on the wall
  • iPhone page
  • /gerir to manage
  • Subscribed calendar

The iPad 2 is stuck on iOS 9, which has no fetch, no CSS Grid and outdated certificates. So the dashboard page is written in ES5 with flexbox only, and the server does every outside request. The page reloads itself when the server or its files change.

Everything in one config file

Nothing personal is in the code. Keys, links and preferences live in config.json; family data lives in data/familia.json. Both are ignored by git.

SettingWhat it does
idiomaLanguage of the whole interface and the subscribed calendar: "en" (default) or "pt".
localWhere you live, for the weather.
calendariosICS links for the agenda (iCloud, Outlook…) and their colours.
transito.tomtomChaveFree TomTom key for live traffic. Without it, travel times come from OSRM, without traffic.
agendaFotos · modoNoitePhoto folder, how often photos change, and night hours.
pinGestaoPIN required to save changes from the management page.
diasAgenda · feriadoMunicipalDays shown in the agenda; your municipal holiday.
ecraFine-tuning: refresh interval, when panels close, when “Don't forget” switches to tomorrow.

Install

You need a PC, Raspberry Pi or NAS that stays on at home, with Node.js 18 or later, and an iPad or any tablet on the same Wi-Fi.

  1. Get the code

    git clone https://github.com/fmrgcarvalho/familydesk.git
cd familydesk
npm install

  2. Create your configuration

    Copy the example and fill in your location and calendar links. Everything else is optional.

    cp config.example.json config.json

  3. Start the server

    The terminal shows the addresses for the iPad and for the management page. On Windows, arrancar.cmd keeps it running and can be started at logon.

    npm start

  4. Put it on the wall

    On the iPad, open the address in Safari, choose Share → Add to Home Screen, set Auto-Lock to Never and turn on Guided Access.
